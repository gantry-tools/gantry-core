# Gantry Core v0.2.0

Gantry Core v0.2.0 is the shared clustering, functional API/CLI, and controlled
configuration-propagation baseline used by the Gantry projects.

This release includes the Phase 2-6 shared contracts and implementations added
after v0.1.1:

- cluster identity, pairing, authenticated transport, membership and fan-out;
- shared cluster CLI and presentation contracts;
- authoritative functional API/CLI coverage and automation contracts;
- secure CLI execution helpers;
- propagation envelopes, dry-run plans, targeting, conflict handling and
  secret references;
- bounded apply/rollback, propagation history, drift profiles and scheduled
  reconciliation;
- distributed failure/recovery certification; and
- the project-wide Go 1.25.0 baseline.

Configuration propagation remains application-level coordination. It is not
database replication, and product runtime/history data remains product-owned.
