# Gantry Core v0.1.0

Gantry Core v0.1.0 is the first stable public-preview release of the shared Go
contracts used by the Gantry applications.

It includes:

- canonical multi-account authentication, authorization, session, CSRF and
  audit primitives;
- shared launcher routing and instance-selection contracts;
- reusable agent, conversation, editor, terminal and workspace behavior;
- compatibility fixtures and a persistent local Go workspace workflow for all
  current consumers.

The public-preview label means the APIs are ready for use across the Gantry
projects, while incompatible changes may still be made before v1.0 with release
notes and coordinated consumer updates.
