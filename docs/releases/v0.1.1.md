# Gantry Core v0.1.1

Gantry Core v0.1.1 establishes the shared foundation for complete, scriptable
HTTP API and CLI coverage across the Gantry Go applications.

It adds:

- a measured source inventory for Cortex, Warden, Trestle, Watchpost,
  Watchpost Agent and Webfleet;
- versioned operation contracts joining HTTP routes, CLI commands,
  authorization, schemas, audit, idempotency and secret handling;
- a common non-interactive CLI grammar and stable exit-code taxonomy;
- execution identities that keep product-local human accounts, API tokens,
  services and future cluster nodes structurally separate;
- bounded strict JSON, structured errors, redaction, confirmations, pagination
  and deterministic output rendering;
- local and authenticated HTTP operation clients with conservative retries;
- a fail-closed contract-test harness for route, website, API, CLI,
  authorization and audit drift; and
- the checkpointed Watchpost-first clustering and propagation roadmap.

This release is the dependency boundary required before consumer repositories
can adopt the new contracts without relying on unpublished module revisions.
